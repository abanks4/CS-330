My approach to designing software is to start by breaking down the requirements into small parts that can be completed step by step. For this projects, it was broken up week to week by adding different elements to the scene such as adding shapes, textures, lighting, and camera movement. One new design skill I used in this project was combining 3D shapes to recreate complex objects. I also learned how modifying rotation, position, and scale can be used to transform a scene. 

In this project the starter code provided some functions that allowed me to apply changes to the elements in the scene without having to write completely new code for each one. This helped reemphasize the importance of having organized code when developing programs. I used an iterative development process in this project by making changes to the scene, running the program, and viewing how the changes affected the scene. While working through each milestone, I became more comfortable with knowing what needed to be added or adjusted in the code to make the necessary changes to the lighting, textures, orientation of the shapes in the scene.

Working with computational graphics and visualizations gave me experience with using OpenGL, 3D shapes, textures, lighting, and camera controls to recreate a scene. I plan on pursuing a career in healthcare information technology. Computational graphics probably will not apply directly to this but the practice of breaking complex problems such as a scene and breaking into smaller parts can be applied across the technology field.
